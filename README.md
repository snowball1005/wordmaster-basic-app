# 워드마스터 BASIC 성장 탐험 앱

## 사용법
`index.html`을 웹 브라우저로 열어 실행합니다. `words.json`은 추출 데이터 검토용이며 앱에는 데이터가 내장되어 있습니다. GitHub 저장소 루트에 `index.html`을 올린 뒤 Render의 Static Site로 배포하세요. Build command 비움, Publish directory `.`입니다.

## 기능
40일 800개 단어 순차 학습(시작 5개/일), 퀴즈, 예문, 배열, 직접 입력, 간격 복습, 별/캐릭터, 아이별 프로필, 부모 보고서 JSON 내보내기/가져오기.

## 유의사항
학습 진도는 각 브라우저의 localStorage에 저장됩니다. 부모 실시간 원격 조회·기기 간 자동 동기화는 제공하지 않습니다. 빈칸 자료의 예문은 원문 빈칸에 표제어를 단순 삽입하여 만든 초안이므로 시제·수·활용형에 따라 자연스럽지 않은 문장이 있을 수 있습니다. 일부 뜻은 어휘 뜻 대신 예문 번역 힌트가 사용되었습니다. 교육용 정식 배포 전에 전수 교정을 권장합니다. 제공 교재를 기반으로 개인 학습용으로 사용하고 저작권을 준수하세요.
