# 워드마스터 BASIC PWA

## 배포
ZIP 압축을 풀고 내부 파일과 `icons` 폴더를 GitHub 저장소 최상위에 업로드합니다.
Render Static Site: Branch `main`, Publish Directory `.`, Build Command `echo ready`.
HTTPS로 배포해야 서비스워커와 홈 화면 설치가 동작합니다.

## 설치
Android Chrome: 웹주소 접속 → 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가.
iPhone Safari: 공유 → 홈 화면에 추가.
처음 한 번 인터넷 연결 상태에서 앱을 실행하고 페이지 로딩을 마쳐야 오프라인 캐시가 준비됩니다.

## 오프라인
화면/단어/문장 데이터는 index.html에 내장되어 오프라인에서 실행됩니다.
학습 기록은 기기의 localStorage에 저장되며 연결 없이 유지됩니다.
오프라인 시 음성 합성은 기기에 저장된 영어 음성의 지원 여부에 따릅니다.
부모 보고서의 기기 간 자동 동기화는 포함되지 않습니다.
브라우저 저장 데이터 삭제 시 학습 기록이 지워질 수 있으므로 JSON 내보내기로 백업하세요.

## 교육 자료 검증
원본 학습 데이터 중 일부 예문과 뜻은 추가 검수가 필요합니다.
